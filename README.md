# KN-RAI-Integracja-sterownika-PLC-z-baza-SQL
Repozytorium projektu w ramach działalności Koła Naukowego Robotyka Automatyka Informatyka (RAI) na Politechnice Poznańskiej. Projekt integracji sterownika Siemens S7-1500 z bazą danych SQL za pośrednictwem middleware (KEPServerEX i OPC Router). Umożliwia automatyczny zapis parametrów ze sterownika PLC w czasie rzeczywistym.
